## Parent contract (durable, from umbrella)

Three labeled Layout presets using existing shapes: **Column** (cylinder),
**Platform** (box), **Plinth** (box). Editable dimensions, floor-relative
placement, then ordinary Layout objects. Presets are creation defaults — not
linked prefab instances or new serialized object kinds. **Do not ship a generic
box preset called `Partition`** in this minimum slice (a wall-like box cannot
own openings or participate in room-boundary semantics; would create a
misleading second-class wall concept). If a freestanding display partition
becomes a repeated need, register it later as an explicit fixture/template.
