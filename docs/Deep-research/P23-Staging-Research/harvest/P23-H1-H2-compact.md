## 1. Durable contracts (H1 constraints + H2 hard boundaries)

- `LayoutDocument`=authored architecture truth; `SceneDocument` not rewritten to compensate; room identity/ownership explicit; no proximity-inferred ownership/adjacency/shared-wall.
- `compileLayoutGeometry()`=single renderer-neutral compiler; Plan+3D gain no consumer-local wall/curve/opening reconstruction; compiled query records + `PlanRenderModel`=Plan geometry source; no upstream canvas/Three hit-test import as second source; Plan/SVG consumes compiled/render-model, never resamples/reinterprets.
- One completed edit/Apply/gesture=at most one `layout` history result, correctly tagged; rejected/cancelled/missing-target/no-op=none; preserve redo where history layer does.
- Candidate edits deterministic+atomic: resolve target → complete candidate → structural+geometry validation → install/commit only on success.
- Visitor/editor isolation unchanged: no editor session/selection/history/controller/renderer/gizmo/snap/guide/Inspector/theme-infra into visitor-safe layout-core or visitor runtime.
- Room-local transforms + explicit `roomId` ownership authoritative; Arrange can read Layout refs, never cross-owner writes (Scene writes Scene-only; Layout writes Layout-only).
- Snap/guide/preview=session-only transient; never `LayoutDocument`/`SceneDocument`/persistence/history/serialized JSON.
- Canonical selection/history deterministic, separate from snapping.

## 5. Canonical operation contracts

### 5.1 Straight-wall exact-size (pure; illustrative names)

```ts
type ResizeStraightWallInput = { roomId: string; segmentId: string; length: number /*m*/; fixed: 'start'|'end' };
type ResizeStraightWallResult = { success: true; document: LayoutDocument; affectedSegmentIds: string[] } | { success: false; message: string };
```
Steps: 1) structural validate/canonicalize input doc via existing layout path; 2) resolve one explicit room+line by ID; 3) reject non-finite/non-positive + unsupported curve; 4) moving endpoint from fixed endpoint + current line dir; 5) update selected + exactly room-ring neighbor sharing moved vertex incl wrap; keep all IDs; 6) preserve room ID/frame/metadata + unrelated rooms/floors verbatim; 7) preserve every opening verbatim (esp meter `offset`; no normalize/rebase as hidden behavior); 8) structural + `validateLayoutDocumentGeometry()` on complete candidate; 9) reject on any boundary/intersection/opening-fit/overlap/vertical; 10) valid candidate → existing editor transaction adapter, one commit. Refinement: `fixed:'end'` moves start so openings move in world with start (offset from start); if preserved offset no longer fits → whole candidate rejects; future “preserve world opening” = separate explicit op owning opening mutation.

### 5.2 Rectangle width/depth

No P23.1 seed replacement; no upstream detection after resize. Verified 4-line rects: keep `LayoutRoom.id/frame`, 4 segment IDs+ordering; solve w/d in room-local boundary coords from explicit anchor; preserve `SceneDocument`+ownership; preserve `LayoutOpening.offset` exactly then canonical validation accept/reject; arbitrary polygons/curves out of P23.1 exact w/d. Inference=negative evidence: never rebuild rooms or generate replacement IDs.

### 5.3 Opening manipulation (one durable coord)

`offset`=physical m from owning segment start. Derived: `start clearance=offset; center=offset+width/2; end clearance=canonical length-(offset+width)`. Center/end numeric fields convert back to `offset`; no persisted extra coords. Straight direct: body drag → `offset` only; start/end width handle → `offset+width` or `width` per handle preserving opposite edge anchor; `segmentId/id/kind/height/sillHeight/profile/connectsRoomIds` unchanged unless field owns them; same validator as numeric; overflow/overlap/vertical invalidity rejects (never silently clamp authored value; do not reuse insertion `snapSegmentOffset` clamping as edit semantics). Hit: port openPlan fixture principle not renderer helpers — true physical span first, then CSS-px edge halo converted via Plan projection; geometry/tangent from compiled/query/Plan render.

### 5.4 Snap resolver (P23.2; pure editor seam `.../layout/plan-snap.ts` — name impl detail)

Accepts `CompiledLayoutQueryGeometry` + raw world pointer + `pixelsPerMeter` + tool/gesture context + source exclusions; generates only context-valid candidates from compiled queries + transient anchors; resolves one winner via umbrella comparator; returns renderer-neutral result + transient guide/marker descriptors. No Svelte/DOM/SVG/Three/Threlte/Scene/history/persistence imports. Promote to `layout-core` only if real non-editor caller needs it. Acquisition: `SNAP_ACQUIRE_RADIUS_PX=8` initial centralized testable default (evidence: Arrange 6px halo; openPlan 5px opening margin, 8px handles/measurement; LibreCAD broad grid-coupled range rejected); `worldRadius=px/pixelsPerMeter`; independent of grid step; test multi-zoom; hysteresis deferred (no evidence for sticky winner in minimum; add release radius only if flicker fixtures prove need). Vocab (context-valid only): 1 endpoint/room corner=compiled `vertex`; 2 opening edge=canonical compiled interval endpoints, opening-relevant context only; 3 intersection=eligible canonical straight/query spans, dedupe self/adjacent deterministically; 4 straight-wall midpoint=authored straight wall midpoint, not tessellated subspan midpoints; 5 orthogonal=transient X/Z from active anchor/ref; 6 nearest span=canonical `projectPointToSpans()` over eligible spans; 7 grid=current effective step, fallback after refs. Curves: existing compiled spans/canonical data; Plan never resamples. Exclusions by stable semantic/source ID pre-generation: dragged object; moving room + owned Layout geometry where self-snap invalid; current wall/vertex source per edit; actively edited opening itself vs trivial self-win. Comparator (mandatory): A) tool/context validity filter; B) semantic priority via explicit per-context rank table (never call/source-array order; opening-edge only in valid context; endpoint/corner outranks generic nearest-span when both valid; rest reconciled in P23.2 plan); C) screen distance within same rank (CSS-px); D) stable key from kind+source/subfeature IDs (never render layer/array/Svelte order). Valid non-grid ref beats grid by contract; grid evaluated as fallback. Rejects LibreCAD call-order tie + nearest-first as semantics; openPlan array tie + component-local endpoint-first as architecture. Output (conceptual): `PlanSnapResult{point: LayoutVec2; kind: candidate-kind|'free'; sourceIds; stableKey: string|null; guides: PlanSnapGuide[]}`; `PlanSnapGuide`=renderer-neutral transient (orthogonal line via anchor; short source-span emphasis; winner marker; optional compact label). No serialization; no history from guides. Gesture order: `raw pointer → context/modifier constraints → P23 ref resolution → grid fallback if none → preview → one commit`; never re-grid winning ref; angle modifiers unchanged unless separately approved.

### 5.6 Visual grammar (P23.6)

Hierarchy (current tokens/surface): 1 authored walls/physical thickness (strongest neutral); 2 opening voids/jambs (clear wall interruption); 3 restrained room fill/name; 4 Layout objects (subordinate to architecture); 5 passive Scene footprints (quieter); 6 transient preview/snap guides (visible, not selection-like); 7 active selection/handles (highest). Winner markers (glyph P23.6 work; screen-constant, `pointer-events:none`, winner-only, ≠ selection handles, no hit/snap authority from marker): endpoint/opening-edge=square/bracket; midpoint=triangle/diamond; intersection=cross/`×`; nearest-span=point+short perpendicular/source emphasis; orthogonal=thin dashed guide + right-angle cue when useful; grid=smallest/quietest, no long guide. Dimensions (drafting grammar only): extension lines, offset line, concise metric label, gap/halo, compact diagonal ticks, presentation-only edge flip/shift; display only truthful contextual (selected straight-wall length; rectangular-room principals); no persisted annotation system. Opening truth: allowed gap/void + neutral jamb/window + selected body/width handles from real P23.3 semantics; forbidden invented hinge/swing/decorative symbol as hit/snap/mutation source.
