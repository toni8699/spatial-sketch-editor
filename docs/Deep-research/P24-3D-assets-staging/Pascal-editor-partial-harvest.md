## Candidate acceptance fixtures (not yet implemented)

1. One Scene ID viewed in Plan/3D; Plan move leaves Y/pitch/roll/scale intact. Derived from item definition/move paths; preservation assertion is Museum-specific.
2. Selected but Plan-ineligible entity keeps canonical selection. Museum-specific extension of selection-routing evidence.
3. View switch during placement/transform cancels and adds no history. Required by Museum; not proven upstream.
4. Equivalent preview updates publish no redundant state and retain immutable baselines. Provenance: live-draft-preview-stores tests.
5. Final preview matches committed candidate; pointer-up must not unexpectedly select a new snap target. Provenance: move overlay commit comments/path.
6. Final handle patch adds exactly one history result; failure and no-op preserve baseline/redo. First part has upstream test evidence; failure/redo assertions must be independently verified in Museum.
7. Opening-straddling T/X insertion rejects the whole Museum command. Provenance: upstream opposite-behavior test above.
8. Wall subdivision retains original-start ID, rebases opening and restores exact IDs on redo. Museum-specific counter-fixture to Pascal replacement-ID behavior.
9. Nearby distinct endpoints do not connect until an explicit accepted join writes Junction identity. Counter-fixture to proximity-based source paths.
