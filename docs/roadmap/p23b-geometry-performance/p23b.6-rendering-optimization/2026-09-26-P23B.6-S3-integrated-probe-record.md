**Status:** this is the historical result of the first integrated attempt. Its implementation ran the structural guard for both inputs of every Wall comparison and measured a net loss. The owner directed a guard recheck; the updated production path is net positive on all four accepted single-Wall fixtures. See the superseding [S3 guard recheck](2026-09-26-P23B.6-S3-guard-recheck.md) and [S6 final evidence](2026-09-26-P23B.6-S6-final-evidence.md). **Initial result:** under that first implementation, the integrated preparation path reused value-equal meshes but had a net loss on every accepted single-Wall move release. That result would have met §11 A-1 without the owner's subsequent correction; it does not abandon the final implementation.

**Owner authorization:** the owner explicitly authorized S3 (M-3m, cross-generation Wall-mesh reuse) in PR #93 on 2026-09-26. This authorization is recorded here. The result below is the plan's mechanical net-benefit gate, not a change to that authorization.

The integrated probe ran on 2026-09-26 in Node v26.7.0 production mode, on Apple M2 / 8 logical CPUs, from the dirty experimental worktree based at `5687b6a7c3f64d499f22c5ca312a0755c2c7a837`. The worktree changes were included in the run. It used five warmups and fifteen measured samples for each of four committed 40-Wall fixtures, with twenty fresh compiled candidate generations per action. The current prepared generation was the only reference. The complete provenance and measurements are in [the JSON data](2026-09-26-P23B.6-S3-integrated-probe-data.json). Neither baseline nor reuse ratchet was read or written.

The unit is **one full-generation preparation**, with per-Wall decisions inside that call. `full` is the same preparation path without a reference; `reuse` is that path with the currently installed generation. Net is `full p50 − reuse p50`. Whole-Room bridge results are separate and do not count as accepted-edit admission.
