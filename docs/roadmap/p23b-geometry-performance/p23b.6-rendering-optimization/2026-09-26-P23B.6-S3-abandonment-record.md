**Historical result:** under the earlier `deepEqualOwnData` comparator, the measured gate indicated abandoning cross-generation prepared-mesh reuse (M-3m). This is not the current S3 decision.

This records the §11 A-1 result for the ratified [P23B.6 plan](2026-09-22-P23B.6-rendering-optimization.md). The S3 net-benefit probe measured the implemented whole-Wall comparator and preparation path on all four committed 40-Wall fixtures, with five warmups and fifteen samples per measurement. It ran in Node 26.7.0 production mode on Apple M2 at base commit `1b5a48b0`; the experimental S3 worktree changes were included. The complete timing report and provenance are in [the JSON evidence](2026-09-26-P23B.6-S3-abandonment-data.json). No baseline or ratchet was written.

The comparator measurement visits every candidate Wall using `wallMeshReuseRefusalReason`; the skipped-build measurement independently builds the Walls classified as value-equal.
